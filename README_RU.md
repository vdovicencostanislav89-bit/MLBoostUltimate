# ML BOOST ULTIMATE — Android-проект

Простой Android-проект на Kotlin для Xiaomi/HyperOS. Включает:
- запуск Mobile Legends, если пакет игры обнаружен;
- базовые сведения о памяти самого приложения;
- уровень заряда и температуру батареи, если Android сообщает их;
- свободное и общее место во внутреннем хранилище;
- простой сетевой тест (не является пингом игрового сервера);
- быстрые переходы в системные настройки;
- рекомендации для Mobile Legends.

## Важно
Приложение не разгоняет CPU/GPU, не разблокирует FPS и не очищает память других приложений. Для этого обычному приложению Android нет безопасного универсального доступа. Не отключайте защиту от перегрева.

## Как собрать APK
1. Установите Android Studio на компьютер.
2. Откройте папку `MLBoostUltimate` как проект.
3. Дождитесь синхронизации Gradle (нужен интернет для загрузки зависимостей).
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK обычно появится в `app/build/outputs/apk/debug/app-debug.apk`.
6. Перенесите APK на телефон и установите. Android может попросить разрешить установку из выбранного источника.

Параметры проекта: minSdk 26, targetSdk 35. APK здесь не собран и проект не протестирован на физическом устройстве; перед установкой проверьте сборку в Android Studio.
